Roadmap

Where A.L.E.X. has been, where it is now, and where it's going. A.L.E.X. is built by PIR®'s volunteer Tech Committee in the open, one careful step at a time.

Why we're building it

PIR®'s committees ran on WhatsApp threads and Zoom: requests got lost, and nobody could see what was in flight. Members and newcomers asked questions the website already answered. A.L.E.X. answers from PIR®'s own pages with sources, and turns requests into tickets a committee can see, claim and resolve.

Now

  • Conversation mode in #ask-alex: members type normally and A.L.E.X. answers in a thread, in that one channel only.
  • Finishing onboarding: every group and medicine channel selectable when you join.
  • Private groups by request: a gentle request desk reviewed by each group's trusted servants, never an automatic click.

Next

  • A separate "ops" helper for server upkeep, so A.L.E.X. stays purely member-facing.
  • Self-serve notification roles (announcement pings, meeting reminders, time zones).
  • Living status boards for each helpdesk.
  • Faster, sharper answers: a cached FAQ, links that jump straight to the quoted sentence, and Claude Haiku if the Tech Committee approves it.

Later (each needs a Tech Committee or Board decision first)

  • A testnet Web3 desk with anonymous, non-transferable service badges: no money, no tokens for sale.
  • A De Vine News submission desk for the newsletter.
  • Telegram, if and when PIR® goes there, with the same safety rules.
  • Verified roles (for example "service role holder") through Discord's Linked Roles.

Stewardship and succession

So A.L.E.X.'s pages outlive any one person (today drasticstatic, Christopher W, holds the tokens that publish them). Details on the sustainability page.

  • [ ] Two owners for PIR®'s GitHub organization, from the fellowship's trusted servants
  • [ ] Publishing through org-owned automation (a GitHub App or an org bot account), not personal tokens
  • [ ] A token register with expiry dates, and a renewal runbook with reminders
  • [ ] Hand-over steps and scheduled backups, tickets included
  • [ ] A GSR desk in A.L.E.X. (/gsr), so the GSR Desk can take tickets
